### Table Scroll & Sticky Column

**Tests:** `@tacc/core-styles` v2.58.4 table scroll and sticky-first-column rules ([Core-CMS #1236](https://github.com/TACC/Core-CMS/pull/1236)).

> [!NOTE]
> Builds on [Sticky Table Column](./v4.40.2-rc1.md#sticky-table-column) (v4.40.2-rc1).

1. Create/Edit a test page.
2. Add a Text plugin inside a styled section (Container, Style, or Section).
3. In "Source" view, paste HTML from [`research-table-current.html` with `<th colspan="2">`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/79cf9d67/tup/html/research-table-current.html).
4. Save.
5. **Refresh page** (after any edit).
6. Scroll the table horizontally using the table scrollbar (not the page scrollbar).
7. Confirm the first column is **not** sticky-pinned.
8. Confirm the table scrolls horizontally inside the section (not clipped).

### Section Full-Bleed Backgrounds

**Tests:** section bleed and in-section horizontal scroll fixes in Core-Styles v2.58.4 ([Core-CMS #1236](https://github.com/TACC/Core-CMS/pull/1236)).

> [!NOTE]
> Extends [Section Background Gaps on Wide Screens](./v4.40.1-rc1.md#section-background-gaps-on-wide-screens) (v4.40.1-rc1).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_page_section_style --replace
    ```
2. Open `/test/test-section-style/`.
3. Set the browser viewport wide (e.g. 1920px).
4. Confirm section backgrounds bleed edge-to-edge with no side gaps for:
    - light
    - muted
    - accent
    - dark
5. On a page with a wide table inside a styled section, scroll the table horizontally.
6. Confirm the section background is not clipped.
7. Confirm wide table content remains scrollable.
