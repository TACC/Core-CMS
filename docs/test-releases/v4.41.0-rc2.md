## Standard Features

> [!TIP]
> **All** portals have these features.

### Table Scroll & Sticky Column

**Tests:** `@tacc/core-styles` v2.58.4 table scroll and sticky-first-column rules ([Core-CMS #1236](https://github.com/TACC/Core-CMS/pull/1236)).

> [!NOTE]
> Builds on [Sticky Table Column](./v4.40.2-rc1.md#sticky-table-column) (v4.40.2-rc1).

1. Create/Edit a test page with a Text plugin that contains a wide table **with** `colspan` or `rowspan` inside a styled section (e.g. paste HTML from [`research-table-current.html` with `<th colspan="2">`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/79cf9d67/tup/html/research-table-current.html)).
2. Save and refresh.
3. Scroll the table horizontally using the table scrollbar.
4. Confirm the first column is **not** sticky-pinned.
5. Confirm horizontal scrolling works (table is not clipped inside the section).

### Section Full-Bleed Backgrounds

**Tests:** section bleed and in-section horizontal scroll fixes in Core-Styles v2.58.4 ([Core-CMS #1236](https://github.com/TACC/Core-CMS/pull/1236)).

> [!NOTE]
> Extends [Section Background Gaps on Wide Screens](./v4.40.1-rc1.md#section-background-gaps-on-wide-screens) (v4.40.1-rc1).

1. On server, run:
    ```sh
    docker exec portal_cms python manage.py create_test_page_section_style --replace
    ```
2. Open `/test/test-section-style/` at a wide viewport (e.g. 1920px).
3. Confirm light, muted, accent, and dark section backgrounds still bleed edge-to-edge with no side gaps.
4. On a page with a wide table inside a styled section, scroll the table horizontally.
5. Confirm section background is not clipped and wide table content remains scrollable.
