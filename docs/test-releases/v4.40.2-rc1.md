### Filter/Sort Table No Results

**Tests:** `html-filter-sort` CDN pin bumped to v1 ([Core-CMS #1227](https://github.com/TACC/Core-CMS/pull/1227)).

1. Create/Edit a test page.
2. Add a Text plugin.
3. In "Source" view, paste the HTML from [`research-table-current.html`@`e4ad21b8`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/e4ad21b8/tup/html/research-table-current.html) ([preview](https://tacc.utexas.edu/research/tacc-research/)).
4. Save.
5. Confirm sorting/filtering still works.
6. Filter to zero results.
7. Confirm a centered "No results found" row spans the table.

### Sticky Table Column

**Tests:** first column of tables is pinned unless table has `colspan` or `rowspan` ([Core-CMS #1228](https://github.com/TACC/Core-CMS/pull/1228)).

> [!TIP]
> If you use the page on which you tested "Filter/Sort Table", edit its Text plugin and skip to step 4.

1. Create/Edit a test page.
2. Add a Text plugin.
3. In "Source" view, paste the HTML from [`research-table-current.html`@`685523a8`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/685523a8/tup/html/research-table-current.html).
4. Save.
5. Scroll the table horizontally, using the table (not the page) scrollbar.
6. Confirm the first column pins.
7. In "Source" view, replace the HTML with [one that has a `<thead>` with a `<th colspan="2">`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/79cf9d67/tup/html/research-table-current.html).
8. Scroll the table horizontally again.
9. Confirm the first column no longer pins.
