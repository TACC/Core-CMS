### Sticky Table Column

**Tests:** first column of tables is pinned unless table has `colspan` or `rowspan` ([Core-CMS #1228](https://github.com/TACC/Core-CMS/pull/1228)).

> [!TIP]
> If you use the page on which you tested "Filter/Sort Table", edit its Text plugin and skip to step 4.

1. Create/Edit a test page.
2. Add a Text plugin.
3. In "Source" view, paste the table from
    [`research-table-current.html`](https://raw.githubusercontent.com/TACC/Core-CMS-Custom/e4ad21b88c6f430d7802acaa413b31ded21c19c4/tup/html/research-table-current.html) ([preview](https://tacc.utexas.edu/research/tacc-research/)).
4. Wrap the `<table>` in a `<div>` that forces horizontal scroll, regardless of screen width\
    <sup>(text just wraps to fit any screen, so the table never overflows on its own)</sup>:
    ```html
    <div class="o-table-wrap o-table-wrap--overflow-scroll" style="white-space: nowrap;">
      <table>...</table>
    </div>
    ```
5. Save.
6. Scroll the table horizontally, using its own scrollbar (not the page's).
7. Confirm the first column pins.
8. Add a `colspan` attribute to a header cell.
9. Scroll the table horizontally again.
10. Confirm the first column no longer pins.
