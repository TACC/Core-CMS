## Standard Features

> [!TIP]
> **All** portals have these features. You may create/edit one test page for all of these.

### Image Gallery Grid

**Tests:** `@extend` replaced with `@mixin` for the gallery grid ([Core-CMS #1226](https://github.com/TACC/Core-CMS/pull/1226)).

1. `make start`
2. Add an "Image Gallery" plugin (`djangocms-tacc-image-gallery`) to a page, nested with a few Picture plugins.
3. Confirm images render in the same responsive grid as before this change.

### Sticky Table Column with Grouped Header

**Tests:** sticky-column pinning for CMS tables with a grouped (`[colspan]`) header ([Core-CMS #1228](https://github.com/TACC/Core-CMS/pull/1228)).

1. `npm ci && npm run build`
2. Confirm the CSS build completes with no errors.
3. Open a CMS table with a grouped (`[colspan]`) header and a `<td>` first column.
4. Scroll it horizontally.
5. Confirm the first column no longer pins (previously it pinned and misaligned with the header).
6. Confirm a table with no `[colspan]`/`[rowspan]` anywhere still pins its first column as before.

### Filter/Sort Table No Results

**Tests:** `html-filter-sort` CDN pin bumped to v1 ([Core-CMS #1227](https://github.com/TACC/Core-CMS/pull/1227)).

1. Load a CMS page with a `js-filtersort` table.
2. Confirm sorting/filtering still works.
3. Filter to zero results.
4. Confirm a centered "No results found" row spans the table.
