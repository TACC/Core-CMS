## Standard Features

> [!TIP]
> **All** portals have these features. You may create/edit one test page for all of these.

### `<details>` `<summary>` and ARIA

**Tests:** preserve `<summary>` and `aria-*` attributes in Text plugin HTML ([v4.40.0-rc7](https://github.com/TACC/Core-CMS/releases/tag/v4.40.0-rc7)).

1. Log in.
2. Open a page with `?edit`.
3. Add/Edit a Text plugin.
4. Switch to "Source" view and paste:
    ```html
    <details>
    <summary>Abstract</summary>
    <p aria-label="anything">Body text.</p>
    </details>
    ```
5. Save, reopen the plugin, and open "Source" view again.
6. Confirm `<summary>` is still a tag (**not** escaped as `&lt;summary&gt;`).
7. Confirm `aria-*` attributes remain.

### Picture Default Caption

**Tests:** Picture plugin falls back to the filer Image's default caption ([v4.40.0-rc8](https://github.com/TACC/Core-CMS/releases/tag/v4.40.0-rc8)).

1. Log in.
2. In Filer, open an Image and set a **Default caption**.
3. Add a Picture plugin using that image, leave the plugin's own caption empty, and publish.
4. Confirm the rendered `<figcaption>` shows the image's default caption.
5. Set the plugin's own caption text and confirm it overrides the default.
6. Add a child plugin to the Picture plugin (no caption text) and confirm the default caption is **not** shown.

### Bootstrap 4 Alert Colors

> [!NOTE]
> Extends [Bootstrap 4 Alerts](./v4.40.0-rc6.md#bootstrap-4-alerts) (tested in rc6) with the remaining Bootstrap 4 context variants.

**Tests:** `success`, `danger`, `warning`, `info` alert colors ([v4.40.0-rc9](https://github.com/TACC/Core-CMS/releases/tag/v4.40.0-rc9)).

1. Log in.
2. `docker exec portal_cms python manage.py create_test_page_alert_style --replace`
3. Open the generated test page.
4. Confirm all 8 alert variants render with the correct Bootstrap color class.
5. Optionally, add a Bootstrap Alert plugin manually and confirm all 8 contexts appear in the **Context** dropdown.
