## Standard Features

> [!TIP]
> **All** portals have these features. You may create/edit one test page for all of these.

### Org Logo Icons

**Tests:** `org_logos` SVG cache-bust query bumped to `2026-03` ([Core-CMS #1233](https://github.com/TACC/Core-CMS/pull/1233)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_social_logos_snippet_test_page --replace
    ```
2. Open `/test/social-logos-snippet-test/`.
3. Confirm footer social logos render (no broken `org_logos` SVGs).
4. Create/Edit a test page.
5. Add a Snippet plugin.
6. Choose or create a Snippet whose **Template** is `snippets/logos-branding.html`.\
    <sup>(**HTML** may be `{# SEE: "Template:" field #}` — same pattern as the social logos snippet.)</sup>
7. Save and view the page.
8. Confirm header/footer branding logos render (no broken SVGs).
9. Open a published News/Blog article that shows share icons.
10. Confirm share icons render (no broken SVGs).

### Footer Social Logos Snippet

**Tests:** footer social icon order and omission via `PORTAL_SOCIAL_MEDIA_PLATFORMS` ([Core-CMS #1232](https://github.com/TACC/Core-CMS/pull/1232)).

> [!TIP]
> If you completed [Org Logo Icons](#org-logo-icons), reuse `/test/social-logos-snippet-test/` and skip to step 3.

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_social_logos_snippet_test_page --replace
    ```
    <sup>(Creates `/test/social-logos-snippet-test/` with a Snippet plugin that loads `snippets/logos-social-media.html`.)</sup>
2. Open `/test/social-logos-snippet-test/`.
3. Confirm footer social icons appear in this order:
    - LinkedIn
    - Instagram
    - Facebook
    - Bluesky
    - YouTube
4. Confirm **no** Threads icon.\
    <sup>(Default `PORTAL_SOCIAL_MEDIA_PLATFORMS` omits it.)</sup>
5. *(Optional)*
    Add `'threads'` to `PORTAL_SOCIAL_MEDIA_PLATFORMS`.
6. Redeploy or restart the CMS.
7. Reload the test page and confirm a Threads icon appears.

### Picture & Bootstrap Figure Captions

**Tests:** `@tacc/core-styles` v2.58.2 figure/caption mixins ([Core-CMS #1234](https://github.com/TACC/Core-CMS/pull/1234)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_picture_test_page --replace
    ```
2. Open `/test/test-picture-style/`.
3. Confirm pictured captions (`<figure>` / `<figcaption>`) look the same as before this release.
4. Create/Edit a test page.
5. Add a Text plugin.
6. In "Source" view, paste semantic and Bootstrap-class figures side by side:
    ```html
    <figure class="figure">
    <img src="https://placehold.co/800x400/336699/white.png?text=Test+Image" alt="Semantic figure">
    <figcaption class="figure-caption">Semantic caption</figcaption>
    </figure>
    <hr>
    <div class="figure">
    <img src="https://placehold.co/800x400/336699/white.png?text=Test+Image" alt="Bootstrap figure">
    <div class="figure-caption">Bootstrap-class caption</div>
    </div>
    ```
7. Save and view the page.
8. Confirm both caption styles match each other (border, color, spacing).
