## Standard Features

> [!TIP]
> **All** portals have these features.

### TACC Site Section Plugin

**Tests:** new TACC Site Section plugin for Core-Styles `o-section` variants ([Core-CMS #1238](https://github.com/TACC/Core-CMS/pull/1238)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_page_section_style --replace
    ```
2. Open `/test/test-section-style/`.
3. Compare the test page and Section plugin fields to [Core-CMS #1238 **UI**](https://github.com/TACC/Core-CMS/pull/1238).

### Bootstrap Alert Admonition Appearance

**Tests:** Bootstrap 4 Alert **Admonition (TACC)** appearance ([Core-CMS #1242](https://github.com/TACC/Core-CMS/pull/1242), [Core-CMS #1247](https://github.com/TACC/Core-CMS/pull/1247)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_page_alert_style --replace
    ```
    <sup>(After `npm run build` and `collectstatic` if CSS is stale.)</sup>
2. Open `/test/test-alert-style/`.
3. Compare rendered alerts and Alert plugin edit form to [Core-CMS #1242 **UI**](https://github.com/TACC/Core-CMS/pull/1242).
4. Confirm the Admonition **warning** row still matches [#1247 **UI**](https://github.com/TACC/Core-CMS/pull/1247) (no change expected).

### Export Page to DOCX

**Tests:** Core-CMS-Plugin-Export-Page ([Core-CMS #1248](https://github.com/TACC/Core-CMS/pull/1248)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_export_page_plugins --replace
    ```
2. Open `/test/test-export-page/`.
3. Download `.docx` from the page tree or CMS toolbar.
4. Compare export to [Core-CMS-Plugin-Export-Page #2 **UI**](https://github.com/TACC/Core-CMS-Plugin-Export-Page/pull/2).

## Deployment

> [!IMPORTANT]
> Developer/deployment test only — not a portal UI smoke test.

### Docker Local Image Tag

**Tests:** local dev Compose image tagged `:local` ([Core-CMS #1243](https://github.com/TACC/Core-CMS/pull/1243)).

1. `make build`
2. Confirm the CMS image is tagged `core-cms:local` (or project-equivalent).
3. `make start`
4. Confirm the website loads.

### CI CMS Image Build

**Tests:** GitHub Actions builds and pushes the `core-cms` image ([Core-CMS #1244](https://github.com/TACC/Core-CMS/pull/1244)).

1. Open the workflow run for this release tag on GitHub Actions.
2. Confirm the CMS image build job succeeds.
