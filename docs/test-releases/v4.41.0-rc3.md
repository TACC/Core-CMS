## Standard Features

> [!TIP]
> **All** portals have these features.

### TACC Site Section Plugin

**Tests:** new TACC Site Section plugin for Core-Styles `o-section` variants ([Core-CMS #1238](https://github.com/TACC/Core-CMS/pull/1238)).

1. On server, run:
    ```sh
    docker exec portal_cms python manage.py create_test_page_section_style --replace
    ```
2. Open `/test/test-section-style/`.
3. Confirm four section types (light, muted, accent, dark) render with expected background and spacing.
4. Add a Section plugin manually.
5. Confirm **Section type** lists the four variants.
6. Open **Advanced** settings and confirm **Tag type** offers semantic choices (e.g. `section`, `article`, `div`).

### Style & Grid Container Sections

**Tests:** legacy Style and Bootstrap 4 Container section QA page ([Core-CMS #1238](https://github.com/TACC/Core-CMS/pull/1238)).

1. On server, run:
    ```sh
    docker exec portal_cms python manage.py create_test_page_container_style --replace
    ```
2. Open `/test/test-container-style/`.
3. Confirm Style and Container blocks (including accent variants) still render as before the Section plugin split.

### Bootstrap Alert Admonition Appearance

**Tests:** Bootstrap 4 Alert **Admonition (TACC)** appearance and warning context mapping ([Core-CMS #1242](https://github.com/TACC/Core-CMS/pull/1242), [Core-CMS #1247](https://github.com/TACC/Core-CMS/pull/1247)).

> [!NOTE]
> Extends [Bootstrap 4 Alert Colors](./v4.40.0-rc10.md#bootstrap-4-alert-colors) (v4.40.0-rc10) with a second appearance.

1. On server, run:
    ```sh
    docker exec portal_cms python manage.py create_test_page_alert_style --replace
    ```
2. Open `/test/test-alert-style/`.
3. Confirm each context shows **Bootstrap (TACC)** and **Admonition (TACC)** columns.
4. Confirm Admonition blocks use `admonition` classes and Cortal `::before` icons (not default Bootstrap alert chrome).
5. Confirm the **warning** admonition uses the warning-style icon/class (not the danger icon).
6. Add or edit a Bootstrap 4 Alert plugin.
7. Set **Appearance** to **Admonition (TACC)** and confirm **Dismissable** is disabled.
8. Set **Appearance** back to **Bootstrap (TACC)** and confirm **Dismissable** is available again.

### Export Page to DOCX

**Tests:** Core-CMS-Plugin-Export-Page ([Core-CMS #1248](https://github.com/TACC/Core-CMS/pull/1248)).

1. On server, run:
    ```sh
    docker exec portal_cms python manage.py create_test_export_page_plugins --replace
    ```
2. Open `/test/test-export-page/`.
3. From the page tree or CMS toolbar, download the page as `.docx`.
4. Open the file and confirm exported content includes Text, Snippet, Link, Style, Grid, Alert, Section, and Card plugin output.

## Deployment

> [!IMPORTANT]
> Developer/deployment test only — not a portal UI smoke test.

### Docker Local Image Tag

**Tests:** local dev Compose image tagged `:local` ([Core-CMS #1243](https://github.com/TACC/Core-CMS/pull/1243)).

1. `make build`
2. Confirm the CMS image is tagged `core-cms:local` (or project-equivalent).
3. `make start` and confirm the site loads.

### CI CMS Image Build

**Tests:** GitHub Actions builds and pushes the `core-cms` image ([Core-CMS #1244](https://github.com/TACC/Core-CMS/pull/1244)).

1. Open the workflow run for this release tag on GitHub Actions.
2. Confirm the CMS image build job succeeds.
