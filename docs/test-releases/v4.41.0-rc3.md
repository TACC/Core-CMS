## Pre-Tested Features

> [!NOTE]
> Already tested on clients ([#1238](https://github.com/TACC/Core-CMS/pull/1238), [#1242](https://github.com/TACC/Core-CMS/pull/1242), [#1247](https://github.com/TACC/Core-CMS/pull/1247), [#1248](https://github.com/TACC/Core-CMS/pull/1248)). Repeat only if you want a spot-check.

### TACC Site Section Plugin

**Tests:** new TACC Site Section plugin for Core-Styles `o-section` variants ([Core-CMS #1238](https://github.com/TACC/Core-CMS/pull/1238)).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_page_section_style --replace
    ```
2. Open `/test/test-section-style/`.
3. Confirm each section type renders with expected background and spacing:
    - light
    - muted
    - accent
    - dark
4. Add a Section plugin manually.
5. Confirm **Section type** lists the four variants above.
6. Open **Advanced** settings on the Section plugin.
7. Confirm **Tag type** offers semantic choices (e.g. `section`, `article`, `div`).

### Bootstrap Alert Admonition Appearance

**Tests:** Bootstrap 4 Alert **Admonition (TACC)** appearance and warning context mapping ([Core-CMS #1242](https://github.com/TACC/Core-CMS/pull/1242), [Core-CMS #1247](https://github.com/TACC/Core-CMS/pull/1247)).

> [!NOTE]
> Extends [Bootstrap 4 Alert Colors](./v4.40.0-rc10.md#bootstrap-4-alert-colors) (v4.40.0-rc10). Warning row: no change expected per [#1247](https://github.com/TACC/Core-CMS/pull/1247).

1. On server, run:
    ```sh
    sudo docker exec portal_cms python manage.py create_test_page_alert_style --replace
    ```
2. Open `/test/test-alert-style/`.
3. Confirm each context shows two columns:
    - **Bootstrap (TACC)**
    - **Admonition (TACC)**
4. In the Admonition column, confirm blocks use `admonition` classes.
5. Confirm Admonition blocks use Cortal `::before` icons (not default Bootstrap alert chrome).
6. Confirm the **warning** admonition uses the warning-style icon/class (not the danger icon).
7. Add or edit a Bootstrap 4 Alert plugin.
8. Set **Appearance** to **Admonition (TACC)**.
9. Confirm **Dismissable** is disabled.
10. Set **Appearance** to **Bootstrap (TACC)**.
11. Confirm **Dismissable** is available again.

**Tests:** Core-CMS-Plugin-Export-Page ([Core-CMS #1248](https://github.com/TACC/Core-CMS/pull/1248)).


4. Open the `.docx` file.

    - Style

## Deployment

> [!IMPORTANT]
> Developer/deployment test only — not a portal UI smoke test.

### Docker Local Image Tag

**Tests:** local dev Compose image tagged `:local` ([Core-CMS #1243](https://github.com/TACC/Core-CMS/pull/1243)).

1. `make build`
2. Confirm the CMS image is tagged `core-cms:local` (or project-equivalent).
3. `make start`
4. Confirm the website loads.

### CI CMS Image Build

**Tests:** GitHub Actions builds and pushes the `core-cms` image ([Core-CMS #1244](https://github.com/TACC/Core-CMS/pull/1244)).

1. Open the workflow run for this release tag on GitHub Actions.
2. Confirm the CMS image build job succeeds.
